# Smart Campus Bot for Navigation and Information Sharing

## Overview

The Smart Campus Bot is a campus navigation and information-sharing system designed to help students, visitors, and other users find important locations within a college campus.

## Objectives

- Provide easy navigation within the college campus
- Help users locate departments and important facilities
- Reduce the difficulty of finding unfamiliar locations
- Provide a simple and user-friendly navigation experience

## Main Features

- Campus location identification
- Navigation between important campus locations
- Route guidance to selected destinations
- Information sharing about campus locations
- User-friendly interface

## Campus Locations

The system can be used to navigate to locations such as:

- Main Gate
- Entrance
- Library
- EC Department
- CSE Department
- Other important campus locations

## Working

The user can access the campus navigation system and select a required destination. The system provides route guidance from the user's starting point to the selected location, helping the user reach the destination more easily.
